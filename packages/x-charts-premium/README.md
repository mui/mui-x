# MUI X Premium

This package is the Premium plan edition of the chart components.
It's part of [MUI X](https://mui.com/x/), an open-core extension of our Core libraries, with advanced components.

## Installation

Install the package in your project directory with:

```bash
npm install @mui/x-charts-premium @mui/material @emotion/react @emotion/styled
```

## Documentation

Visit [https://mui.com/x/react-charts/](https://mui.com/x/react-charts/) to view the full documentation.
